-----> Glide aggregate - it is a glide object which allow us to perform statistical operation on the tables 
 
           we have few aggregate functions to perform the things  

        1.COUNT - count function will give the count of records inside the table

        Syntax : 
            
                 var  ga = new GlideAggregate('table_name');
                 ga.addAggregate("COUNT");
                 ga.applyfilter method(addQuery / addEncodedQuery);
                 ga.query();
                 if(ga.next()){

                  var result = ga.getAggregate("COUNT");
                  gs.info("The total no of records in the incident table "+result);
                 }

          User case 2 : Get the count of priority records 
            
  
                 Note :in this scenario we use groupBy to apply the filter on the field
                       we get the each field value record count
            Script :  
                              var countPr = new GlideAggregate('incident');
                                countPr.addAggregate('COUNT');
                                countPr.groupBy('priority');
                                countPr.query();
                                while(countPr.next()){
                                	var dis=countPr.getDisplayValue('priority');
                                	var result=countPr.getAggregate('COUNT');
                                	gs.info(dis +' : '+" "+result);
                                }
                   



        2.MIN  -    to get the min value of a field(imp - the field must and should store the numeric data)

            User case 1 :  Finding the min cost of a ci 

             setGroup(false) - it will control the groupBy 

               script : 

                    var minCost = new GlideAggregate('cmdb_ci');
                     minCost.addAggregate('MIN','cost');
                     minCost.setGroup(false);
                     minCost.query();
                     while(minCost.next()){
                     	var result = minCost.getAggregate('MIN','cost');
                     	gs.info("The minimum cost of a ci"+result);
                     }
