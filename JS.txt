---> increment and decrement :

            decrement : decrement the original value by 1(-1)
                 |
              ex:

  ---> Looping control statements :
      
      --- The loop will iterate until the condition matchs

    1. for loop   : the loop iterates until the stopping conditions is matched

        i=0 is the initial condition -- the loop starts from here
        i<=10 is the stopping condition -- the loop stops 
        i++ the value is incremented

     Syntax :

         for(var i=0; i<=10; i++){
          //output statement
         } 
          

    2. while loop  : 
           
          the loop will check the condition and then execute the statement


          syntax : 
              
              var i =1 ;
              while(i<=10){
                //output statement;
                i++;
              }

              ex : 
                         var i=1;
                         while(i<=20){
                             console.log(i);
                             i++;
                         }
